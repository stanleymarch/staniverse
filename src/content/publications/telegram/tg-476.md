В щебетальной ленте Browser Use [попалось видео](https://x.com/browser_use/status/1896352364858376372), где кто-то заказывает еду через Uber Eats из своего Cursor через подключенный MCP сервер. Давайте теперь всё переведём на русский.

[Model Context Protocol (MCP)](https://modelcontextprotocol.io/introduction) был создан и [анонсирован компанией Anthropic](https://www.anthropic.com/news/model-context-protocol) в ноябре 2024 года как открытый стандарт, который решает ключевую проблему ИИ-ассистентов — их изоляцию от данных и систем, где эта информация хранится. Протокол стандартизирует подключение ИИ-моделей к различным источникам данных и инструментам. Вместо создания отдельных интеграций для каждого источника данных, разработчики могут использовать что-то одно, что значительно упрощает масштабирование ИИ-систем.

Поддержку MCP сначала завезли в настольном приложении Claude (Claude Desktop App), дав пользователям возможность интегрироваться [с источниками данных, в том числе локальными](https://modelcontextprotocol.io/quickstart/user). На начало марта 2025 года экосистема существенно расширилась — протокол теперь поддерживается инструментами для разработки, такими как [Cursor](https://docs.cursor.com/context/model-context-protocol) и [Cline/Roo Code](https://docs.cline.bot/mcp-servers/mcp-quickstart), ИИ-ассистентами и платформами для их создания. Фактически, MCP может быть интегрирован в любую систему, использующую генеративный ИИ, делая его универсальным стандартом для взаимодействия с данными.

В серверной части экосистемы представлены различные категории решений для работы с кодом, облачными хранилищами, базами данных, поисковыми системами, средствами коммуникации и многими другими сервисами. Обновляемый список некоторых MCP-серверов [доступен на GitHub.](https://github.com/modelcontextprotocol/servers)

В качестве «видео на вечер» предлагаю [запись воркшопа «Building Agents with Model Context Protocol»](https://youtu.be/kQmXtrmQ5Zg) с Махешем Мурагом из Anthropic с AI Engineer Summit 2025 в Нью-Йорке. Там и про философии, лежащую в основе MCP, и про то как разработчики могут использовать его для создания контекстно-богатых ИИ-приложений и агентных решений.
