# Лаборатория: experiments/&lt;name&gt;/

Стандарт одного эксперимента:

```
experiments/<name>/
├── package.json        # свой; build → dist/
├── ...                 # любой стек
└── dist/               # результат сборки (в .gitignore эксперимента)
```

Правила:

1. **Путь.** Базовый путь сборки обязан совпадать с публичным префиксом:
   Vite — `base: "/lab/<name>/"`, в чистом HTML — относительные ссылки от корня эксперимента.
2. **Деплой.** `.github/workflows/lab.yml` собирает только изменившиеся каталоги
   (`dorny/paths-filter` + matrix) и синхронизирует `experiments/<name>/dist/`
   в `s3://<bucket>/lab/<name>/`. Секреты те же, что у основного сайта
   (`YC_ACCESS_KEY_ID`, `YC_SECRET_ACCESS_KEY`, `YC_BUCKET`, `YC_ENDPOINT`).
3. **Каталог.** Эксперимент описывается карточкой контента
   `src/content/experiments/<slug>.md` (статус `live`) — тогда `/lab/` ссылается на
   него, а разбор механики живёт на странице `/experiments/<slug>/`. Фронтматтер:
   `summary` (что это и как этим пользоваться), `href` — адрес, где опыт запускается,
   `repo` — репозиторий, если код вне монорепозитория, `types` (игра, песочница,
   приложение, инструмент, арт-опыт), `platforms` (мобильные, гарнитуры, десктоп),
   `capabilities` (ИИ, бэкенд, физика, звук, мультиплеер), `stack` и `complexity`
   (1 — одна механика, 2 — механика со счётом или физикой, 3 — несколько состояний и
   прогрессия). Тело страницы — разбор: что внутри, как играть, где это лежит в коде.
   Фильтры и сортировка на `/lab/` строятся из этих полей; ряд без значений не
   показывается, а карточка ведёт и к запуску, и к описанию.
4. **Самодостаточность.** Эксперимент не тянет стили/шрифты основного сайта:
   это отдельное приложение, случайно совпадающее по духу.
5. **Изоляция кода.** Каталог не участвует в сборке Astro-сайта; свои зависимости,
   свой lock-файл, свой `.gitignore` с `dist/`.


Порог входа — минимальный: даже одностраничный тест заслуживает своего каталога
и строки в `experiments.ts`. Страница-описание в `/projects/<name>/` появляется
только когда у опыта есть история, которую стоит рассказать; размер кода не
критерий, критерий — есть ли нарратив.

Подробности бакета, секретов и Cache-Control — `docs/deploy/yandex-object-storage.md`.
